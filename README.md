# BASE_HTCONDOR
# Подготовка развертывания 

1. Разместите скрипт ssh_setup.sh на узлах

2. Сделайте скрипт исполняемым chmod +x ssh_setup.ssh

3. Запустите скрипт настройки SSH ssh_setup.ssh

4. Передать Публичный ключ узла на другие узлы

   4.1 Проверить соединение ssh

5. Запустить через Ansible скрипт htcondor-cluster.yml
